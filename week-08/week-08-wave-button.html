Each opens more, rising like level meters.

Each level in each configuration, at rest, pointed at, pressed and turned off. Hover is drawn as it ends: Add to playlist’s bars playing, Save’s recording written in, Skip’s tape up to full. Add to playlist is a toggle, so it shows twice: before it is added (coral, five bars) and after (a ring, the bars flat). Turned off, coral gives way to a quiet blue-grey. Then the depth: each button closed, opened, and one level deeper.
